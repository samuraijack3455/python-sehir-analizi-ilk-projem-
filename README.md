# python-sehir-analizi-ilk-projem-
python ile şehir listeleme ve basit analiz projesi(ilk projem)
Nasıl Kullanılır

sehir_analiz.py dosyasını çalıştırın.

Program sizden şehir isimleri isteyecek.

Şehir eklemek için yazın ve Enter’a basın.

Bitirmek için q yazın.

Program ekrana:

Girilen şehirler

Şehirlerin kopyası

İsminiz ve büyük harfli versiyonu

Uzun/kısa şehir sayısı ve toplam şehir sayısı
bilgilerini yazdıracak.

Öğrenilen Konular

while ve for döngüleri

Listeye veri ekleme (append)

Liste kopyalama (copy)

Mutable ve immutable veri tipleri

String işlemleri (upper)

Fonksiyon ve veri analizi
